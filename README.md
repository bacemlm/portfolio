## ✨ Highlights

- **Modern UI** — component-based interface built with React and TypeScript.
- **Responsive styling** — powered by Tailwind CSS.
- **Motion & interactions** — GSAP, Motion, and smooth scrolling with Lenis.
- **Optimized assets** — image processing tools powered by Sharp.
- **Production build** — Vite bundling, TypeScript checks, and a custom prerendering step.
- **GitHub workflows** — automation configuration maintained in `.github/workflows`.

## 🚀 Getting Started

### Prerequisites

Install a current version of **Node.js** and **npm** compatible with the project's Vite release.

### Installation

```bash
git clone https://github.com/bacemlm/portfolio.git
cd portfolio
npm ci
```

### Local development

```bash
npm run dev
```

Open the local URL displayed in the terminal.

### Production build

```bash
npm run build
npm run preview
```

The build script checks TypeScript, builds with Vite, and runs the project's prerendering script.

## 📜 Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Type-check, build, and prerender |
| `npm run preview` | Preview the production build locally |
| `npm run typecheck` | Validate TypeScript without emitting files |
| `npm run images` | Run the image optimization script |
| `npm run social` | Generate social-sharing images |
